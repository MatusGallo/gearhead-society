# Gallery photos

One folder per gallery, named after its `slug` in `src/data/galleries.ts`:

    src/assets/galleries/pressure-2025/001.jpg
    src/assets/galleries/pressure-2025/002.jpg

Photos are shown in file-name order. The site builds optimized thumbnails and a large view
automatically; the download button serves the original file, so export originals at the
size people may download (e.g. 2500 px on the long edge, sRGB JPEG).
